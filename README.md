# 새김자막 (Saegim Subtitles)

유튜브 동영상 자막 위에 한자어의 훈음(뜻과 소리)과 외래어의 원어를 잠깐 보여주는 크롬 확장 프로그램입니다.

## 하는 일

- 현재 보고 있는 유튜브 동영상의 자막 트랙을 자동으로 불러와 화면에 표시합니다.
- 자막 속 한자어에는 훈음(뜻과 소리)을, 외래어에는 원어를 함께 보여줍니다.
- 사용자가 팝업에 직접 붙여넣거나 파일로 올린 자막 스크립트(SRT 또는 타임스탬프 텍스트)도 지원합니다.
- 영상 재생 시간에 맞춰 자막을 동기화합니다.

## 개인정보 처리 원칙

- 모든 처리는 **사용자의 브라우저 안에서만** 이루어집니다.
- 자막을 불러오기 위해 유튜브에 보내는 요청 외에는 어떤 외부 요청도 하지 않습니다.
- 개발자나 제3자 서버로 데이터를 전송하지 않으며, 애널리틱스·광고 SDK를 포함하지 않습니다.
- 붙여넣은 스크립트나 시청 기록은 영구 저장되지 않으며, 탭을 새로고침하거나 닫으면 사라집니다.

자세한 내용은 [privacy-policy.html](./privacy-policy.html)을 참고하세요.

## 권한

- `host_permissions: *://*.youtube.com/*` — 유튜브 동영상 자막을 불러오고 재생 화면 위에 자막 병기 화면을 그리기 위해 필요합니다. 유튜브가 아닌 사이트에서는 동작하지 않습니다.
