새김자막 — 개인정보처리방침

최종 수정일: 2026-10-30

요약: 새김자막은 기본 상태에서 어떤 사용자 데이터도 외부 서버로 전송하지 않습니다. 모든 동작은 사용자의 브라우저 안에서 이루어집니다. 다만 사용자가 직접 동의한 경우에만 아래의 선택 기능이 동작합니다. 동의하지 않아도 새김자막의 모든 기능은 똑같이 사용할 수 있습니다.

  • 새 곡 사전 만들기 — 곡 사전이 아직 없는 곡을 볼 때, 그 영상의 ID와 한국어 자막 글자를 보내 새 곡 사전을 만듭니다. 설치 직후(이미 설치한 경우 이 기능이 들어간 업데이트 직후) 한 번 묻습니다.
  • 용례 개선 참여(개발 기간 2026년 12월 11일까지) — 낱말이 들어 있는 자막 문장 한 개를 보냅니다.

적용 시점: "새 곡 사전 만들기"는 버전 0.5.0부터, "용례 개선 참여"는 해당 기능이 포함된 버전부터 적용됩니다. 그 이전 버전은 어떤 사용자 데이터도 전송하지 않습니다.

수집하는 정보

기본 상태 (동의하지 않았을 때)

없습니다. 새김자막은 이름, 이메일, 시청 기록, 검색어, 위치 등 어떤 개인 식별 정보도 수집·저장·전송하지 않습니다. 이 상태에서는 사용자의 유튜브 시청 데이터를 외부로 보내지 않습니다.

곡 사전 묶음(새 곡의 뜻 데이터)은 몇 시간마다 한 번 통째로 내려받습니다. 이때는 어떤 영상을 보고 있는지 보내지 않습니다.

"새 곡 사전 만들기"에 동의한 경우

새 K팝 곡의 사전을 만들어 그 곡을 보는 모든 사용자에게 뜻을 보여 주기 위해, 사용자가 동의 화면에서 "예, 보낼게요"를 누르거나 팝업에서 직접 켠 경우에만 다음을 전송합니다.

  • 보내는 때 — 곡 사전이 아직 없는 영상에서, 유튜브가 제공하는 한국어 수동 자막(자동 생성·자동 번역 자막 제외)을 불러왔을 때. 같은 영상은 7일 안에 다시 보내지 않습니다.
  • 보내는 것 — 그 영상의 영상 ID, 한국어 자막의 글자와 시작 시각·길이(가사), 확장 프로그램 버전.
  • 보내지 않는 것 — 계정·이메일, 쿠키, 시청 기록(다른 영상 목록), 영상 주소의 다른 파라미터, 사용자를 구분하는 고유 번호, 사용자가 직접 고친 자막 스크립트.
  • 서버 접속 정보 — 인터넷 요청에는 IP 주소가 따라옵니다. IP 주소는 요청 남용(과다 요청) 방지에만 쓰고 24시간 뒤 삭제하며, 영상 ID·자막과 연결해 저장하지 않습니다.

"용례 개선 참여"에 동의한 경우 (개발 기간 한정, 선택)

뜻 판별 규칙과 시험 세트를 만드는 데 쓰기 위해, 안내 화면에서 사용자가 직접 동의 버튼을 누른 경우에만 다음을 전송합니다.

  • 보내는 것 — 사전에 있는 낱말이 들어 있는 자막의 한국어 문장 한 개의 글자(텍스트)와 그 문장에서 표시된 낱말.
  • 보내지 않는 것 — 영상 주소(URL)·영상 ID·영상 제목·채널, 재생 시각, 계정·이메일, 사용자를 구분하는 고유 번호, 사용자가 직접 고친 자막 스크립트.
  • 서버 접속 정보 — 서버 접속 기록(IP)은 수집한 문장과 연결해 저장하지 않습니다.

사용 목적

  • "새 곡 사전 만들기"로 받은 자막은 그 곡의 곡 사전(낱말과 뜻)을 만드는 데에만 사용합니다. 만든 곡 사전은 모든 사용자에게 내려받는 곡 사전 묶음에 들어갑니다.
  • "용례 개선 참여"로 받은 문장은 동음이의어의 뜻을 가르는 규칙을 만들고 시험하는 데에만 사용합니다.
  • 광고, 사용자 분석, 판매에는 사용하지 않습니다.

동의 방법과 철회

  • "새 곡 사전 만들기"는 설치 직후(이미 설치한 경우 이 기능이 들어간 업데이트 직후) 열리는 안내 화면에서 "예, 보낼게요" 또는 "아니요"를 고릅니다. 답하지 않고 화면을 닫으면 꺼진 상태로 남고, 다음 업데이트 때 한 번만 더 묻습니다.
  • 두 기능 모두 기본값은 꺼짐이고, 동의하지 않아도 기능은 동일합니다.
  • 언제든 확장 팝업의 설정("자막을 보내 새 곡 사전 만들기")에서 끄거나 켤 수 있으며, 끄는 즉시 전송이 중단됩니다.
  • 이미 전송된 자막·문장에는 사용자를 구분할 수 있는 정보가 없어 어느 사용자의 것인지 알 수 없으므로, 개별 사용자의 요청으로 찾아서 삭제할 수는 없습니다.

확장 프로그램 권한과 사용 목적

  • 호스트 권한(*://*.youtube.com/*) — 유튜브 페이지에서 현재 재생 중인 영상의 자막 트랙을 읽어, 한자어·외래어 위에 뜻을 보여주는 오버레이를 그리기 위해 사용합니다. 기본 상태에서 자막 데이터는 그 페이지 안에서만 처리되고 어디로도 전송되지 않습니다. 동의한 경우에만 위에 적은 내용이 전송됩니다.
  • storage 권한 — 사용자가 직접 고친 자막 스크립트, 동의 여부, 내려받은 곡 사전 묶음, 곡 사전 요청을 보낸 영상 ID와 시각(7일 안 중복 전송 방지용)을 기기 안(chrome.storage.local)에만 저장합니다. 고친 자막 스크립트는 동의 여부와 관계없이 사용자의 브라우저를 벗어나지 않습니다.
  • 서버 통신 — 확장은 별도 권한을 추가하지 않고, 동의한 경우에만 아래 "수신 서버"로 보냅니다.

수신 서버

  • 곡 사전 요청 수신·곡 사전 묶음 배포: https://211.233.206.154 (「모두의 AI 실험실」이 제공하는 클라우드 서버, 개발자가 운영)
  • 곡 사전 묶음 배포(내려받기 전용, 사용자 데이터를 받지 않음): Netlify

보관과 삭제

  • "새 곡 사전 만들기"로 받은 자막(가사) 원문은 곡 사전을 만든 뒤 남기지 않습니다. 남는 것은 그 곡의 곡 사전(낱말·한자 원어·뜻)과 영상 ID뿐입니다.
  • 서버 접속 IP 주소는 24시간 뒤 삭제합니다.
  • "용례 개선 참여"로 받은 문장 원문은 개발 기간이 끝나면 삭제하고, 그로부터 만든 사전·규칙·시험 세트 결과만 남깁니다.

제3자 공유와 처리

받은 자막·문장은 판매하거나 광고 목적으로 제공하지 않습니다. 저장과 분석, 곡 사전 생성을 위해 「모두의 AI 실험실」이 제공하는 클라우드와 AI 서비스를 사용합니다. 이 AI 서비스에는 자막 글자만 전달되며 IP 주소는 전달되지 않습니다. 동의하지 않은 사용자의 데이터는 수집하지 않으므로 해당 사항이 없습니다.
