새김자막 — 개인정보처리방침

최종 수정일: 2026-11-19

요약: 새김자막은 기본 상태에서 어떤 사용자 데이터도 개발자 서버로 보내지 않습니다. 자막 처리와 뜻 표시는 사용자의 브라우저 안에서 이루어집니다. 곡 사전이 없는 영상에서 사용자가 "Request Saegim" 버튼을 누를 때만 그 영상의 ID와 한국어 자막을 보내 새 곡 사전을 만듭니다. 버튼을 쓰지 않아도 다른 기능은 똑같이 쓸 수 있습니다.

적용 시점: 이 방침은 "Request Saegim" 버튼이 포함된 버전부터 적용됩니다. 그 전 버전(0.5.0부터)은 안내 화면이나 팝업에서 직접 켠 사용자에 한해 재생 중 자동으로 보냈고, 0.5.0 이전 버전은 사용자 데이터를 보내지 않았습니다.

보내는 정보

  • 보내는 때 — 곡 사전이 없고 유튜브의 한국어 수동 자막(자동 생성·자동 번역 자막 제외)이 있는 영상에서 버튼을 누를 때. 처음 누를 때는 보내는 내용과 쓰임을 알리고 확인을 받습니다.
  • 보내는 것 — 그 영상의 영상 ID, 한국어 자막의 글자와 시작 시각·길이, 확장 프로그램 버전.
  • 보내지 않는 것 — 이름, 계정, 이메일, 쿠키, 다른 영상의 시청 기록, 영상 주소의 다른 값, 사용자를 구분하는 고유 번호, 사용자가 직접 고친 자막 스크립트.
  • 서버 접속 정보 — 인터넷 요청에는 IP 주소가 따라옵니다. 서버는 IP 주소 원본을 저장하지 않고, 아래 표의 해시 값만 남용 방지와 중복 집계 방지에 씁니다.
  • 이전에 자동 전송을 직접 켠 사용자 — 그 설정은 사용자가 끄기 전까지 유지되어, 곡 사전이 없는 영상의 같은 정보를 재생 중에 보냅니다(같은 영상은 7일에 한 번). 새로 켜도록 권하지 않으며 팝업이나 안내 화면에서 끌 수 있습니다.

곡 사전 묶음(곡별 뜻 데이터)은 주기적으로 통째로 내려받고, 곡을 요청한 뒤에는 준비됐는지 보려고 최대 6분 동안 30초마다 다시 받습니다. 묶음을 받을 때는 어떤 영상을 보고 있는지 보내지 않습니다.

사용 목적

  • 받은 자막은 그 곡이 원곡 가사인지 확인하고 그 곡의 곡 사전(낱말과 뜻)을 만드는 데에만 씁니다.
  • 만든 곡 사전은 곡 사전 묶음에 들어가 그 곡을 보는 모든 새김자막 사용자에게 쓰입니다.
  • 영상 ID는 공식 K팝 채널의 영상인지 확인하고 곡을 구분하는 데 씁니다. 곡별 요청 수는 어떤 곡을 먼저 준비할지 정하는 데 씁니다.
  • 광고, 사용자 분석, 신용 평가, 판매에는 쓰지 않습니다.

받는 곳

  • 개발자 서버 — https://211.233.206.154 (「모두의 AI 실험실」이 제공하는 클라우드 서버, 개발자가 운영). 곡 요청을 받고 곡 사전 묶음을 내줍니다.
  • AI 서비스 — 「모두의 AI 실험실」이 제공하는 AI 서비스에 자막 글자와 곡 제목·아티스트를 보내 곡 사전을 만듭니다. IP 주소는 전달하지 않습니다.
  • YouTube Data API(Google) — 서버 목록에 없는 영상은 영상 ID로 채널·제목·자막 유무·길이를 확인합니다. 자막과 IP 주소는 전달하지 않습니다.
  • Netlify — 곡 사전 묶음을 내려받는 곳입니다. 사용자가 보낸 데이터를 받지 않습니다.

기기 안에 저장하는 것

chrome.storage.local에 다음을 저장하며 개발자에게 보내지 않습니다: 사용자가 직접 고친 자막 스크립트, 새김 표시 언어, 버튼 첫 확인 여부, 자동 전송 설정, 내려받은 곡 사전 묶음, 곡 요청을 보낸 영상 ID와 시각(7일 뒤 지움), 업데이트 알림.

선택과 삭제

  • 버튼을 누르지 않으면 아무것도 보내지 않습니다. 첫 확인 화면에서 취소해도 보내지 않습니다.
  • 자동 전송을 켠 적이 있으면 팝업("Also send automatically while watching")이나 안내 화면에서 끌 수 있고, 끄면 자동 전송이 멈춥니다.
  • 확장을 삭제하면 기기 안에 저장한 내용도 함께 지워집니다.
  • 서버에는 사용자를 구분하는 정보가 없어 누가 보낸 요청인지 찾을 수 없습니다. 특정 영상의 곡 사전과 요청 수를 지우길 원하면 영상 주소를 아래 메일로 보내 주세요.

  • 호스트 권한(*://*.youtube.com/*) — 재생 중인 영상의 자막을 읽어 뜻을 표시하고, 영상 제목 아래에 요청 버튼을 보이는 데 씁니다.

  • 서버 통신 — 별도 권한을 추가하지 않고, 위에 적은 경우에만 개발자 서버로 보냅니다. 원격 코드는 받거나 실행하지 않습니다.

English summary

By default, Saegim sends no user data to the developer's server. Only when you press Request Saegim on a video without a song dictionary does it send the video ID, the Korean subtitle text with its timing, and the extension version. The first press asks you to confirm. Users who turned on automatic sending in an earlier version keep that choice until they turn it off.

The data is used to check the song and build its song dictionary, which is then available to all Saegim users. It goes to the developer's server (211.233.206.154) and the Modu AI Lab AI service. The video ID may be checked with the YouTube Data API.

Subtitle text is deleted when processing ends. The server keeps the song dictionary, song and processing records, hashed subtitle-line fingerprints, and a request count per video that does not say who asked. IP addresses are not stored as they are: a daily-changing hash is deleted within 24 hours.

The use and transfer of information received from this extension adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is not sold and is not used for advertising or creditworthiness.
