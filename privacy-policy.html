새김자막 — 개인정보처리방침

최종 수정일: 2026-10-17

요약: 새김자막은 기본 상태에서 어떤 사용자 데이터도 외부 서버로 전송하지 않습니다. 모든 동작은 사용자의 브라우저 안에서만 이루어집니다. 다만 개발 기간(2026년 12월 11일까지)에는 사용자가 직접 동의한 경우에만 아래 "동의한 경우에 수집하는 정보"에 적힌 내용을 전송하는 선택 기능이 제공됩니다. 동의하지 않아도 새김자막의 모든 기능은 똑같이 사용할 수 있습니다.

적용 시점: 위 선택 기능은 해당 기능이 포함된 버전부터 적용됩니다. 현재 게시된 버전(0.3.3)에는 이 기능이 없으며 어떤 사용자 데이터도 전송하지 않습니다.

수집하는 정보

기본 상태 (동의하지 않았을 때)

없습니다. 새김자막은 이름, 이메일, 시청 기록, 검색어, 위치 등 어떤 개인 식별 정보도 수집·저장·전송하지 않습니다. 이 상태에서는 사용자의 유튜브 시청 데이터를 외부로 보내지 않습니다.

동의한 경우에 수집하는 정보 (개발 기간 한정, 선택)

뜻 판별 규칙과 시험 세트를 만드는 데 쓰기 위해, 확장을 처음 실행할 때 안내 화면에서 사용자가 직접 동의 버튼을 누른 경우에만 다음을 전송합니다.

  • 보내는 것 — 사전에 있는 낱말이 들어 있는 자막의 한국어 문장 한 개의 글자(텍스트)와 그 문장에서 표시된 낱말.
  • 보내지 않는 것 — 영상 주소(URL)·영상 ID·영상 제목·채널, 재생 시각, 계정·이메일, 사용자를 구분하는 고유 번호, 사용자가 직접 고친 자막 스크립트.
  • 서버 접속 정보 — 인터넷 요청에는 IP 주소 같은 접속 정보가 따라올 수 있습니다. 서버 접속 기록(IP)은 수집한 문장과 연결해 저장하지 않도록 합니다.

사용 목적

수집한 문장은 동음이의어의 뜻을 가르는 규칙을 만들고, 그 규칙이 틀린 뜻을 보여주지 않는지 시험하는 데에만 사용합니다. 광고, 사용자 분석, 판매에는 사용하지 않습니다.

동의 방법과 철회

  • 동의는 첫 실행 안내 화면에서 선택합니다. 동의하지 않아도 기능은 동일합니다.
  • 언제든 확장 팝업의 설정에서 끌 수 있으며, 끄는 즉시 전송이 중단됩니다.
  • 이미 전송된 문장은 사용자를 구분할 수 있는 정보가 없어 어느 사용자의 것인지 알 수 없으므로, 개별 사용자의 요청으로 찾아서 삭제할 수는 없습니다.

확장 프로그램 권한과 사용 목적

  • 호스트 권한(*://*.youtube.com/*) — 유튜브 페이지에서 현재 재생 중인 영상의 자막 트랙을 읽어, 한자어·외래어 위에 뜻을 보여주는 오버레이를 그리기 위해 사용합니다. 기본 상태에서 자막 데이터는 그 페이지 안에서만 처리되고 어디로도 전송되지 않습니다. 동의한 경우에만 위에 적은 문장 한 개가 전송됩니다.
  • storage 권한 — 사용자가 특정 영상에 대해 직접 고친 자막 스크립트와 동의 여부를 기기 안(chrome.storage.local)에만 저장합니다. 고친 자막 스크립트는 동의 여부와 관계없이 사용자의 브라우저를 벗어나지 않으며, 개발자를 포함한 그 누구도 서버를 통해 열람할 수 없습니다.
  • 서버 통신 권한 — 동의한 경우에 위 문장을 보내기 위한 수신 서버 주소에 한해 사용합니다.

보관과 삭제

수집한 문장 원문은 개발 기간이 끝나면 삭제하고, 그로부터 만든 사전·규칙·시험 세트 결과만 남깁니다.

제3자 공유와 처리

수집한 문장은 개발자가 직접 분석하며 판매하거나 광고 목적으로 제공하지 않습니다. 개발 기간 중 저장과 분석을 위해 「모두의 AI 실험실」이 제공하는 클라우드와 AI 서비스(Claude, Anthropic)를 사용할 수 있습니다. 동의하지 않은 사용자의 데이터는 수집하지 않으므로 해당 사항이 없습니다.

내장 사전 데이터의 출처

이 확장은 국립국어원 「한국어 학습용 어휘 목록」(공공누리 제1유형)과 한국어 위키낱말사전(CC BY-SA 4.0)을 참고해 만든 한자어·외래어 사전을 내장하고 있습니다. 이는 사용자 개인정보가 아니라 확장 프로그램 자체에 포함된 정적 콘텐츠입니다.
